# P:accine 학생/교수 UI 및 AI 데이터 처리 기획

## 1. 제품 한 줄 정의

P:accine은 의과대학 시험지, 사진자료, 정답지, 학생 풀이 로그를 문항 단위로 구조화하여 학생에게는 개인화 복습 경로를, 교수자에게는 다음 수업 보강 포인트를 제공하는 학습성과 피드백 OS이다.

핵심은 문항 생성 자체가 아니라 `문항-정답-사진자료-분과-세부주제-평가항목-학생풀이결과`를 한 DB로 연결하는 것이다.

## 2. 참고 레퍼런스

### AMBOSS Educator Tool

AMBOSS는 교수자 기능에서 assignment 생성, learner progress, completion, initial/final correct rate, time per question, question/system/discipline/competency별 분석, personalized recommendation을 제공한다.

참고 링크:
- https://support.amboss.com/hc/en-us/articles/30034537472657-Educator-Feature-Data-and-Analytics
- https://www.amboss.com/us/knowledge/amboss-educator-tool-accessing-data-analytics/
- https://www.amboss.com/int/institutions/educator-tool
- https://www.amboss.com/us/features?tab=teach

P:accine에 가져올 점:
- 교수자용 assignment/배포 관리
- 학생별/코호트별 completion, correct rate, time per question
- system/discipline/competency 기반 대시보드
- 개인화 학습 추천

P:accine의 차별점:
- 해외 Qbank가 아니라 학교가 실제로 보유한 HWP/PDF 시험지, 정답지 XLSX, 사진자료 PDF를 입력으로 사용
- 한국 의과대학 내신/과정시험/PMA/임종평 문항 양식에 맞춘 구조화
- 교수자가 다음 강의 보강에 바로 쓸 수 있는 단원별/평가항목별 약점 리포트

### Osmosis

Osmosis는 강의자료와 학습 일정, 퀴즈, 플래시카드, spaced repetition을 연결하는 학습 플랫폼으로 설명된다.

참고 링크:
- https://www.osmosis.org/features
- https://www.elsevier.support/osmosis/answer/osmosis-your-personal-learning-assistant

P:accine에 가져올 점:
- 강의자료 기반 학습 경로
- 퀴즈와 플래시카드 연결
- 복습 주기 추천

### UWorld/AMBOSS식 학습 모드

의대생에게 익숙한 문제풀이 방식은 크게 `시험 모드`, `학습 모드`, `오답 복습`, `단원별 세션`이다.

P:accine에 가져올 점:
- 시간 제한 시험 모드
- 해설 즉시 확인 학습 모드
- 틀린 문항만 보기
- 특정 분과/주제/평가항목 필터로 세션 생성

## 4. 교수자 UI

### 교수 홈

목적:
- 오늘 교수자가 봐야 할 일만 보여준다.

배치:
- 상단: 최근 구조화된 시험지, 검수 필요 문항 수, 공개 가능 세트 수
- 중앙: 분과별 약점 히트맵
- 우측: 다음 수업 보강 추천
- 하단: 최근 업로드/최근 배포/최근 학생 활동

핵심 카드:
- `문항 구조화`: PDF/HWP 시험지와 정답지 업로드
- `라벨링 대기`: AI가 붙인 라벨 검수
- `학생 풀이 현황`: 완료율, 정답률, 시간/Q
- `보강 추천`: 다음 수업에서 다룰 주제

### 시험지 구조화

목적:
- 기존 자료를 문항 DB로 바꾼다.

입력:
- 시험지 PDF/HWP
- 사진자료 PDF
- 정답지 XLSX
- 해설 HWP/PDF
- 평균/표준편차/문항별 정답률 CSV 또는 수동 입력

화면 배치:
- 왼쪽: 업로드 박스
- 중앙: 구조화 결과 요약
- 오른쪽: 검수 미리보기 링크와 오류 목록

요약 지표:
- 추출 문항 수
- 정답 매핑 수
- 사진자료 연결 수
- 해설 추출 수
- 검수 필요 문항 수

### 문항 라벨링/검수

목적:
- 학생 분석에 필요한 최소 라벨을 빠르게 확정한다.

화면 배치:
- 좌측 필터: 분과, 주제, 자료 유형, 검수 상태
- 중앙: 문항 카드
- 우측: 라벨 패널

필수 라벨:
- 대분과
- 세부 주제
- 평가 항목
- 정답
- 공개 가능 여부

AI 추천 라벨:
- 임상 단계
- 인지 수준
- 오답 유발 포인트
- 이의제기 위험도
- 자료 유형

교수 조작:
- 라벨 승인
- 라벨 수정
- 학생 공개 여부 선택
- 해설 보강 메모

### 수업 리포트

목적:
- 다음 강의/보강 수업을 설계한다.

화면 배치:
- 상단: 전체 평균, 완료율, 고위험 주제
- 중앙: 대분과 -> 세부 주제 히트맵
- 하단: 보강 추천 리스트
- 우측: 문항별 상세 테이블

교수자에게 보여줄 핵심 문장:
- "학생들은 폐렴 진단기준은 잘 맞히지만, 항생제 선택에서 약합니다."
- "심전도 자료해석형 문항에서 시간/Q가 길고 정답률이 낮습니다."
- "정답률이 낮지만 변별도도 낮은 문항은 문항 자체 검토가 필요합니다."

지표:
- 단원별 정답률
- 평가항목별 정답률
- 자료 유형별 정답률
- 평균 풀이 시간
- 문항별 변별도
- 오답 집중 선지
- 이의제기 위험 문항
- 공개 후 복습 참여율

### 배포/과제 설정

목적:
- 승인 문항만 학생에게 학습/시험 세트로 배포한다.

설정:
- 대상 학년/분반
- 공개 기간
- 학습 모드/시험 모드
- 시간 제한
- 해설 즉시 공개 여부
- 사진자료 공개 여부
- Anki export 허용 여부

### 아카이브

목적:
- 시험지와 문항을 재사용 가능한 교육 자산으로 만든다.

배치:
- 분과별 서재
- 시험 회차별 세트
- 자료 유형별 미디어 DB
- 공개 가능 세트
- 교수 검수 완료 세트

## 5. 학생 UI

### 학습 홈

목적:
- 학생이 오늘 무엇을 풀고 복습해야 하는지 바로 보게 한다.

배치:
- 상단: 오늘의 추천 세션
- 중앙: 대분과별 성취도 카드
- 우측: 다음 시험까지 남은 기간, 완료율
- 하단: 최근 오답/복습 카드

핵심 카드:
- `오늘 풀 문항`: 추천 20문항
- `약점 TOP 3`: 정답률 낮은 주제
- `오답 복습`: 다시 풀어야 할 문항
- `Anki 카드`: 다운로드/동기화

### 나의 서재

목적:
- AMBOSS/Allen의 서재처럼 분과를 중심으로 진입한다.

배치:
- 분과 카드 그리드
- 각 카드에 완료율, 정답률, 약점 항목 표시

분과 카드 예시:
- 호흡기: 62% 완료, 약점 `폐기능검사`
- 순환기: 48% 완료, 약점 `ECG`
- 감염: 71% 완료, 약점 `항생제 선택`

### 문제 풀기

목적:
- 학생이 원하는 방식으로 문제 세션을 만든다.

모드:
- 시험 모드: 시간 제한, 해설 나중 공개
- 학습 모드: 해설 즉시 공개
- 오답 모드: 틀린 문항만
- 자료해석 모드: X-ray/CT/ECG/병리 문항만
- 시험지 모드: 특정 회차 그대로 풀기

필터:
- 대분과
- 세부 주제
- 평가 항목
- 난이도
- 자료 유형
- 공개 세트

### 문항 화면

배치:
- 상단: 문항 번호, 분과/주제 태그
- 중앙: 지문, 사진자료, 표
- 하단: 선지
- 우측 또는 하단 drawer: 힌트, 관련 개념, 해설

학습 모드에서 제공:
- 힌트 1: 지문에서 중요한 단서 하이라이트
- 힌트 2: 감별해야 할 개념
- 힌트 3: 관련 강의록/개념 노트
- 해설: 정답 이유, 오답 이유, 자료 해석 포인트

시험 모드에서는 숨김:
- 힌트
- 해설
- 관련 개념

### 분석/피드백

목적:
- 학생이 점수가 아니라 학습 행동으로 바꿀 수 있는 피드백을 받는다.

보여줄 지표:
- 대분과별 정답률
- 세부 주제별 정답률
- 평가 항목별 정답률
- 자료 유형별 정답률
- 평균 풀이 시간
- 반복 오답 개념
- 전체 대비 나의 위치

추천 문장 예시:
- "호흡기 전체 정답률은 평균 수준이지만, 폐기능검사 해석형 문항에서 약합니다."
- "순환기 ECG 문항은 정답률보다 풀이 시간이 길어, 해석 자동화가 아직 부족합니다."
- "감염 항생제 선택 문항은 오답 선지가 반복되어 Anki 카드 복습을 추천합니다."

### 개념 노트/그래프

목적:
- Obsidian Graph처럼 문항, 강의록, 개념, 사진자료를 연결한다.

노드:
- 문항
- 개념
- 강의록
- 사진자료
- 오답 선지
- Anki 카드

사용 흐름:
- 문항 풀이 후 `이 개념 보기`
- 관련 문항 추천
- 같은 사진자료 유형 문항 추천
- 오답 개념을 플래시카드로 변환

## 6. AI 데이터 처리 파이프라인

### 1단계: 수집

입력 자료:
- 시험지 PDF/HWP
- 사진자료 PDF
- 정답지 XLSX
- 해설 파일
- 강의록/PPT
- 학생 풀이 로그
- 평균/표준편차/문항별 정답률

### 2단계: 구조화

룰 기반 처리:
- 문항 번호 추출
- 지문/선지 분리
- 정답지 XLSX 매핑
- 사진 N-m 라벨 기반 이미지 연결
- 교시/회차/문항번호 식별

AI 처리:
- 지문 의미 기반 대분과 추천
- 세부 주제 추천
- 평가 항목 추천
- 임상 단계 추천
- 자료 유형 설명 생성
- 오답 유발 포인트 생성

중요 원칙:
- 정답, 문항번호, 사진자료 매핑은 AI가 아니라 룰 기반/파일 구조 기반으로 처리한다.
- AI는 라벨 초안과 피드백 문장 생성에 사용한다.

### 3단계: 검수

교수/조교 검수 항목:
- 정답 맞는지
- 사진자료 연결 맞는지
- 대분과/세부 주제 맞는지
- 평가 항목 맞는지
- 학생 공개 가능 여부
- 개인정보/저작권 검토

### 4단계: 학생 풀이

수집 로그:
- 문항별 정오답
- 선택 선지
- 풀이 시간
- 힌트 사용 여부
- 재풀이 여부
- 해설 열람 여부
- Anki export 여부

### 5단계: 분석

룰/통계 기반:
- 정답률
- 완료율
- 평균 풀이 시간
- 반복 오답
- 단원별 약점
- 자료 유형별 약점

AI 기반:
- 학생용 피드백 문장 생성
- 교수용 보강 추천 문장 생성
- 유사 문항 추천
- 오답 개념 요약
- Anki 카드 초안 생성

### 6단계: 보강 추천

교수용 출력:
- 보강 우선 주제
- 다시 설명해야 할 평가 항목
- 학생들이 오래 걸린 자료해석 유형
- 공개하면 좋은 복습 세트
- 문항 자체 검토 필요 후보

학생용 출력:
- 오늘 풀 문제
- 오늘 볼 개념
- 오늘 만들/받을 Anki 카드
- 다시 풀어야 할 오답 세트

## 7. 핵심 기능 우선순위

### MVP 1순위

- 시험지 PDF/HWP 구조화
- 정답지 XLSX 매핑

## 8. UI 제작 필요 여부

지금 단계에서는 UI 제작이 필요하다. 이유는 기능보다 교수님/평가자가 보는 첫인상이 중요하기 때문이다.

필요한 화면:
- 교수 홈
- 시험지 구조화 화면
- 문항 라벨링/검수 화면
- 교수 수업 리포트
- 학생 학습 홈
- 학생 문제풀이 화면
- 학생 분석 화면

우선 만들 화면:
1. 교수 시험지 구조화/검수 화면
2. 교수 수업 리포트 화면
3. 학생 문제풀이/분석 화면

디자인 방향:
- 기존 PNUMED 후기 사이트처럼 카드, 필터, 리스트 중심의 앱형 UI
- AMBOSS처럼 좌측 네비게이션과 분석 대시보드
- Allen의 서재처럼 분과별 카드 그리드
- 과도한 문장보다 숫자, 태그, 히트맵, 추천 카드 중심

## 9. 차별화 문장

문항을 새로 만드는 AI가 아니라, 학교가 이미 가진 시험 데이터를 학습성과 피드백으로 바꾸는 시스템입니다.

교수자에게는 다음 수업에서 무엇을 보강해야 하는지 보여주고, 학생에게는 다음 시험을 위해 어떤 개념과 문항을 다시 봐야 하는지 제안합니다.

P:accine은 의과대학 내부 문항과 사진자료를 `학습 가능한 데이터베이스`로 바꾸는 도구입니다.
