# Choice Explanation Authoring Harness

목적: 학생이 문제를 푼 뒤 “왜 이 선지는 맞고, 왜 이 선지는 아닌지”를 바로 학습할 수 있도록 선지별 해설을 작성한다. 단순히 정답 번호를 반복하거나 “정답 선지와 더 직접적으로 연결된다”라고 쓰는 해설은 실패로 본다.

## 1. 기본 원칙

- 해설 작성은 반드시 `문항 이해 -> 판단 기준 -> 선지별 개념 해설 -> Anki 카드` 순서로 진행한다.
- 문항 이해 단계에서는 `무엇을 묻는지`, `어떤 평가 항목인지`, `어떤 기준으로 선지를 판단해야 하는지`를 먼저 한 문장으로 정리한다.
- 해설은 `문항 전체 해설`이 아니라 `각 선지의 학습 해설`이어야 한다.
- 각 선지는 최소한 `개념 정의 -> 지문/선지와의 연결 -> 선택/배제 이유` 순서로 설명한다.
- “정답은 4번입니다”만으로 끝내지 않는다. 각 선지의 개념이 지문 조건과 어떻게 맞거나 어긋나는지 각각 쓴다.
- 원문 해설이 짧으면 그대로 복붙하지 말고, 강의록/RAG/교과서 근거로 학습 가능한 문장으로 보강한다.
- 근거가 부족하면 `needs_review=true`로 표시하되, 학생 화면에는 의미 없는 placeholder 문장을 노출하지 않는다.

## 2. 문항 극성 처리

### 일반 문항

- 기준에 맞는 선지: 지문 단서가 해당 개념과 어떻게 연결되는지 설명한다.
- 기준에서 벗어나는 선지: 그 개념은 무엇인지, 왜 이 지문 조건과 맞지 않는지 설명한다.

### “틀린 것은?” 문항

- 틀린 진술: 어떤 개념·시점·기전·적응증이 틀렸는지 정확히 짚는다.
- 맞는 진술: 본문에는 “정답이 아님”을 반복하지 말고, 해당 개념이 왜 성립하는지만 설명한다.
- 금지 표현: “이 선지는 정답이 아닙니다. 정답 선지가 더 직접적입니다.”
- 금지 표현: “이 선지는 맞는 설명으로 처리됩니다.”
- 금지 표현: “따라서 ‘틀린 것은?’ 문항에서는 정답이 아닙니다.”
- 권장 방식: UI 라벨에서만 `맞는 설명/틀린 진술`을 표시하고, 해설 본문은 개념 설명만 작성한다.

## 3. 선지별 해설 필수 구조

각 선지 해설은 아래 필드를 가진다.

```json
{
  "question_understanding": {
    "concept_path": "대분류 > 세부주제 > 하위개념",
    "asked_concept": "이 문항이 묻는 핵심 개념",
    "assessment_domain": "진단 | 검사 | 치료 | 병태생리 | 예후 등",
    "task": "학생이 수행해야 하는 판단 과제",
    "decision_rule": "선지를 판단하는 기준"
  },
  "choice_number": "1",
  "choice_text": "선지 원문",
  "is_correct": false,
  "question_polarity": "negative",
  "statement_status": "true_statement",
  "rationale": "학생에게 실제로 도움이 되는 선지별 해설",
  "learning_points": [
    {"label": "개념", "body": "핵심 개념 정의"},
    {"label": "왜 맞는가/왜 틀린가", "body": "선지 판단 기준"},
    {"label": "기억 포인트", "body": "다음에 풀 때 떠올릴 압축 포인트"}
  ],
  "evidence": [
    {"title": "근거 자료명", "page_start": 12, "snippet": "짧은 근거 요약"}
  ],
  "needs_review": false
}
```

## 4. 작성 금지 문장

- `정답은 N번입니다`로만 끝나는 문장
- `이 문항은 knowledge를 확인하기 위한 문항입니다`
- `정답 선지와 더 직접적으로 연결됩니다`
- `원문 해설이 짧아 교수 검토가 필요합니다`
- `지문에서 결정 단서를 먼저 표시한 뒤...`
- `저장된 해설만으로는 개별적으로 배제하기 어렵습니다`
- `이 선지는 맞는 설명으로 처리됩니다`
- `따라서 ‘틀린 것은?’ 문항에서는 정답이 아닙니다`
- `이 선지는 이 문항에서 맞는 설명으로 처리됩니다`
- 선지의 의학 개념을 설명하지 않고 답 번호만 비교하는 문장

## 5. 좋은 해설 예시: 두개유합증

문항: `두개유합증(craniosynostosis)에 대한 설명이다. 틀린 것은?`

1번 선지: `두개천장(cranial vault)의 봉합이 조기에 유합되면, 봉합선에 대해 직각방향의 골성장이 감소한다.`

좋은 해설:

> 두개천장(cranial vault, calvaria)은 뇌를 덮는 두개골 지붕이고, 봉합선은 두개골 뼈 사이의 성장판 역할을 합니다. 두개유합증에서는 봉합이 너무 일찍 닫히면 그 봉합선에 수직인 방향의 골성장이 제한되고, 열린 봉합 방향으로 보상성 성장이 일어납니다.

4번 선지: `시상봉합(sagittal suture)의 정상적인 유합은 1세 전후에 시작되어 10세 초반에 마무리 된다.`

좋은 해설:

> 시상봉합(sagittal suture)은 양쪽 두정골 사이를 정중선에서 잇는 봉합입니다. 이 정답지 기준에서는 시상봉합의 정상 유합 시작 시점을 10세 초반으로 보므로, 정상 유합이 1세 전후에 시작된다는 서술은 너무 이릅니다. 시상봉합이 병적으로 조기 유합되면 전후로 긴 주상두(scaphocephaly)가 나타날 수 있습니다.

## 6. RAG 근거 사용 규칙

근거 우선순위:

1. 원문 정답 및 해설
2. 해당 과목 강의록/정리족/출족
3. 로컬 교과서 DB
4. 외부 지식 DB 스타일 참고
5. 교수/조교 검토

주의:

- 외부 레퍼런스 문장을 그대로 베끼지 않는다.
- RAG snippet은 문장 하나를 그대로 붙이는 용도가 아니라, 해설의 판단 근거로 사용한다.
- 근거가 충돌하면 `needs_review=true`로 둔다.
- 학생에게는 “근거 불충분” placeholder 대신, 최소한 어떤 개념을 확인해야 하는지 보여준다.

## 7. Anki 카드 생성 규칙

Anki 카드는 `해설 문장`이 아니라 `개념 기억 문장`이어야 한다.

좋은 카드:

```text
두개유합증에서 조기 유합된 봉합선에 {{c1::수직}}인 방향의 두개골 성장은 {{c2::제한}}된다.
Metopic suture의 조기 유합은 {{c1::trigonocephaly}}를 유발할 수 있다.
```

나쁜 카드:

```text
{{c1::정답은}} 4번입니다.
이 문항은 {{c1::틀린 진술}}을 고르는 문제입니다.
```

카드 기준:

- 자연스러운 문장이어야 한다.
- 빈칸은 핵심 개념, 질환명, 검사명, 약물명, 방향성, 수치 기준에만 뚫는다.
- 한 카드에는 1~2개의 cloze만 둔다.
- “정답”, “문항”, “선지”, “지문” 같은 시험 메타 단어는 cloze로 만들지 않는다.

## 8. 생성 프롬프트 템플릿

```text
너는 의대생용 문항 해설 작성자다.
아래 문항과 선지, 정답, 원문 해설, RAG 근거를 보고 선지별 해설을 작성하라.

작성 목표:
- 먼저 문항 전체를 이해하고, `question_understanding`에 묻는 개념과 판단 기준을 작성하라.
- 학생이 각 선지를 눌렀을 때, 해당 선지가 왜 맞거나 틀린지 학습할 수 있어야 한다.
- 답 번호를 반복하지 말고, 해당 선지의 의학 개념을 설명하라.
- “틀린 것은?” 문항이면 `statement_status`에는 틀린 진술을 `false_statement`, 맞는 진술을 `true_statement`로 표시하되, 해설 본문에는 판정 문장을 쓰지 말고 개념 설명만 작성하라.
- 원문 해설이 짧으면 RAG 근거와 일반 의학 지식으로 보강하되, 근거 충돌 시 needs_review=true로 표시하라.
- Anki 카드는 자연스러운 개념 문장에서 핵심 단어만 cloze 처리하라.

출력 JSON:
{
  "question_understanding": {
    "asked_concept": "...",
    "assessment_domain": "...",
    "task": "...",
    "decision_rule": "..."
  },
  "choice_explanations": {
    "1": {
      "statement_status": "true_statement | false_statement | distractor",
      "rationale": "...",
      "learning_points": [
        {"label": "개념", "body": "..."},
        {"label": "판단 기준", "body": "..."},
        {"label": "기억 포인트", "body": "..."}
      ],
      "needs_review": false
    }
  },
  "anki_cards": [
    {
      "plain_text": "...",
      "anki_text": "...",
      "source_choice": "1",
      "needs_review": false
    }
  ]
}
```

## 9. QA 체크리스트

- 일부 선지만 해설이 있고 나머지 선지는 비어 있지 않은가?
- “틀린 것은?” 문항에서 정답이 아닌 선지를 오답처럼 설명하지 않았는가?
- 각 선지 해설에 해당 선지의 의학 개념이 들어 있는가?
- Anki 카드가 문항 메타 문장이 아니라 개념 문장인가?
- 근거가 부족한 경우 `needs_review=true`로 표시했는가?
- 학생 화면에서 선지를 클릭하면 해당 선지 바로 아래 해설이 펼쳐지는가?
