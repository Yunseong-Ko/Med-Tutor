# P:accine 6인 작업 배분 보드

## 목표

PMA/임종평 및 과정시험 자료를 문항 단위 데이터베이스로 만들기 위해, AI가 자동으로 하기 어려운 원문 확인, 사진자료 매핑, 교육 태그 검수를 팀원별 작업 단위로 나눈다.

## 작업 레인

| 레인 | 담당 | 핵심 업무 | 산출물 |
| --- | --- | --- | --- |
| 1 | 팀원 1 | 시험지 HWP/PDF 파일명 표준화, 과목/시험일/교시 메타데이터 입력 | source manifest |
| 2 | 팀원 2 | 문항번호, 지문, 선지, 정답, 해설 분리 오류 확인 | question QA log |
| 3 | 팀원 3 | 사진 N-m 규칙 기반 제시자료 매핑, modality/진단/핵심 소견 라벨링 | media_asset DB |
| 4 | 팀원 4 | 대분과, 세부 주제, 평가 항목, 인지 수준 taxonomy 정리 | tag dictionary |
| 5 | 팀원 5 | 학생 풀이 흐름, 힌트, 오답 피드백, Anki export 사용성 확인 | student test script |
| 6 | 팀원 6 | 교수 문항 검토 기준, 수업 리포트 항목, 인터뷰 질문 정리 | faculty review checklist |

## 이번 주 금요일 미팅 전 준비물

- 임종평/PMA 예시 파일 1세트 구조화 결과 캡처
- 사진자료 PDF에서 `사진 N-m` 매핑 예시 5개
- 대분과-세부주제-평가항목 taxonomy 초안
- 교수자 수업 리포트 예시 화면
- 학생 문제 풀이/오답 피드백 예시 화면

## AI가 맡는 일

- 문항번호/선지/정답/사진자료 후보의 1차 추출
- 문항별 대분과, 세부 주제, 평가 항목, 오답 포인트 라벨 초안 생성
- 학생 개인 피드백 문장과 Anki 카드 초안 생성
- 교수자 수업 리포트 요약 문장 생성

## 사람이 반드시 확인할 일

- 정답과 해설의 정확성
- 사진자료의 문항 연결 적절성
- 제시자료 비식별화 및 사용 승인 여부
- 교육 태그가 실제 강의 단원과 맞는지
- 학생에게 공개 가능한 문항인지
