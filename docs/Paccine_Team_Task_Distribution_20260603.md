# P:accine 팀원 업무 배분안

## 0. 현재 GitHub 기준 구현 상태

브랜치: `codex/pma-question-pipeline`

최근 구현된 핵심 기능:

- HWP/PDF 과정시험/기출 문항 구조화
- 문항별 `stem`, `stimulus`, `choices`, `answer`, `explanation`, `media_refs` 저장
- 정답지 XLSX 매핑
- 교수용 문항 생성/검토/아카이브/수업 리포트 UI
- 학생용 과목 서재 UI
- 학생용 구조화 문항 세트 선택 및 문제풀이 UI
- 학습 모드에서 선지 선택 후 정답/해설 즉시 확인
- 부산대학교 의과대학 커리큘럼 기반 16개 과목 카드

현재 구조화된 데이터 예시:

| 자료 | 문항 수 | 정답 매핑 | 이미지 연결 문항 | 텍스트 제시자료 |
| --- | ---: | ---: | ---: | ---: |
| 신경 및 특수감각기학 2차 | 142 | 138 | 39 | 54 |
| 정신의학 과정시험 | 133 | 115 | 5 | 14 |
| 인간·사회·의료 1차 | 105 | 105 | 5 | 23 |
| 인간·사회·의료 2차 | 64 | 64 | 0 | 24 |
| 임상의학종합평가 1교시 | 80 | 80 | 0 | 2 |

현재 가장 중요한 병목:

- `<그림>` 텍스트는 잡히지만 실제 이미지가 일부 문항에 자동 연결되지 않음.
- 문항별 과목/단원/평가항목 라벨링이 아직 교수·학생이 쓰기 좋은 수준이 아님.
- 학생이 문제를 풀 수는 있지만, 오답 기록/개념 연결/복습 카드까지는 아직 연결이 약함.
- 교수 리포트는 목업 수준이라 실제 데이터 기반 지표와 라벨 체계가 필요함.

## 1. 전체 목표

1차 목표는 `문항 생성 앱`이 아니라 `학교 시험 자료를 학생 학습과 교수 피드백에 재사용 가능한 DB로 만드는 것`이다.

작업 파이프라인:

```text
시험지/정답지/사진자료 업로드
-> 문항 단위 구조화
-> 정답/해설/이미지 검수
-> 과목/단원/평가항목 라벨링
-> 학생 문제풀이
-> 오답/취약 개념 피드백
-> 교수 수업 리포트
```

## 3. 의대생 3명 업무

의대생은 의학적 맥락, 시험 구조, 학생 체감 UX를 맡는다. 기술 구현보다 `이 문항이 어떤 단원/개념을 묻는지`, `학생이 어디서 막히는지`, `교수님이 무엇을 보고 싶어할지`를 정리하는 역할이다.

### 의대생 1: 문항 구조 QA 및 정답/해설 검수

목표:

- 자동 추출된 문항이 실제 시험지와 맞는지 확인한다.
- 학생에게 풀릴 수 있는 문항과 검수 필요한 문항을 나눈다.

확인할 자료:

해야 할 일:

- 문항 번호가 빠지거나 중복된 곳 찾기
- 지문/제시자료/선지/해설이 잘못 분리된 문항 표시
- 정답이 잘못 붙은 문항 표시
- 해설이 5번 선지 뒤에 붙어버린 문항 표시
- 학생에게 공개 가능/비공개/검수필요 문항을 구분

### 의생공 신입생 1: 이미지/제시자료 DB 정리

목표:

- HWP/PDF에서 추출된 이미지를 문항과 연결 가능한 자료 DB로 정리한다.

현재 이미지 저장 구조:

```text
data_private/course_exams/media/{source_exam}/BIN0001.bmp
data_private/course_exams/media/{source_exam}/BIN0002.bmp
...
```

현재 문항 JSON 구조:

```json
{
  "question_number": 7,
  "stimulus": "<그림>",
  "media": {
    "has_image_or_data_reference": true,
    "media_refs": []
  }
}
```

목표 구조:

```json
{
  "question_number": 7,
  "stimulus": null,
  "media": {
    "has_image_or_data_reference": true,
    "media_refs": [
      {
        "media_id": "COURSE_2_20251103_NEURO_SPECIAL_SENSES_2차_BIN0001",
        "storage_id": "BIN0001",
        "match_method": "manual_review",
        "match_confidence": 1.0,
        "needs_review": false
      }
    ]
  }
}
```

해야 할 일:

- 이미지 파일 전체 목록 확인

- 실제 이미지 파일을 열어보고 문항 번호와 맞는 후보 연결
- 각 이미지에 자료 유형 라벨 붙이기

자료 유형 라벨:

## 7. 1주차 우선순위

### Priority 1: 신경및특수감각기학 2차를 데모 완성도 기준으로 정리

이유:

- 현재 문항 142개, 정답 138개, 이미지 연결 문항 39개로 가장 데모 가치가 높다.

- 이미지 누락 문제도 명확히 보여줄 수 있다.

해야 할 것:

- Q1~Q30 구조 검수
- 이미지 문항 Q7, Q9, Q10 등 확인
- 단원/평가항목 라벨 30개 붙이기

### Priority 2: 이미지 매핑 문제 해결
